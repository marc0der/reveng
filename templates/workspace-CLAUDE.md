# Reveng workspace

This directory is a reverse-engineering workspace produced by [reveng](https://github.com/marc0der/reveng). It is an aggregate working directory — not a code repository — combining raw legacy artefacts with analytical outputs generated by reveng's agents.

## Workspace layout

Inputs (you provide):

- `screenshots/` — UI screenshots of the legacy application (`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.webp`).
- `transcripts/` — stakeholder interview transcripts (`.txt`).
- `src/` — the legacy application's source code. Any language, framework, or database stack — the `application-developer` and `database-analyst` agents detect what's present and adapt.

Outputs (generated):

- `output/html/*.html` — semantic HTML mockups of each screenshot (`image-to-html`).
- `output/transcripts/*_curated.txt` — sanitised interview transcripts (`curate-transcript`).
- `output/domain-analysis.md` — strategic DDD analysis (`business-analyst`).
- `output/interaction-analysis.md` — screens and workflows (`interaction-analyst`).
- `output/application-analysis.md` — application source-code analysis (`application-developer`).
- `output/database-analysis.md` — schema and routine analysis (`database-analyst`).
- `output/PRD.md` — synthesised Product Requirements Document (`product-manager`).
- `output/features/FT-*.md` — individual feature specifications (`prd-to-features`).

## Conventions

- Use British English in all generated documentation.
- Treat all legacy code as potentially undocumented — never assume documentation exists.
- Do not assume any particular technology stack — the analysing agents detect the stack present in `src/` and adapt their exploration accordingly.

## Agents and skills

This workspace ships with reveng's agents and skills under `.claude/agents/<name>/AGENT.md` and `.claude/skills/<name>/SKILL.md`. They were copied here by `reveng init` and are listed in `.gitignore`. Re-run `reveng init` to refresh; existing files are skipped, so local edits are preserved.

Invoke agents either by prompting Claude in this workspace with a request matching the agent's description, or via the `reveng` CLI (`reveng curate`, `reveng synth`, `reveng decompose`), which dispatches to the appropriate agent.
